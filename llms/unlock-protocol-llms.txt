# Unlock Protocol

> Unlock Protocol is an open-source, community-governed protocol for onchain memberships and
> subscriptions. Creators deploy "locks" (membership smart contracts) that mint time-based,
> optionally recurring membership NFTs ("keys") on Ethereum, Base, Optimism, Polygon, Arbitrum
> and other networks. The hosted Locksmith API adds off-chain conveniences: metadata storage,
> event ticketing, QR-code verification, fiat (Stripe) payments, webhooks, and email delivery.
> Governance sits with the Unlock DAO and the Unlock Protocol Foundation.

Generated by API Evangelist from the provider's docs and this repository's artifacts (2026-07-21).

## APIs

- [Locksmith API](https://docs.unlock-protocol.com/tools/locksmith/): hosted REST API — metadata, tickets, checkout configs, receipts, Stripe fiat payments, webhooks. Base URL: https://locksmith.unlock-protocol.com
- [Locksmith API reference](https://docs.unlock-protocol.com/category/api): per-operation reference documentation
- [Unlock Subgraphs](https://docs.unlock-protocol.com/tools/subgraph/): GraphQL indexes of the Unlock contracts per network. Dev endpoint: https://subgraph.unlock-protocol.com/<chainId>
- [Smart Contracts API](https://docs.unlock-protocol.com/core-protocol/smart-contracts-api/Unlock): Unlock factory + PublicLock membership contract interfaces
- [RPC Provider](https://docs.unlock-protocol.com/tools/rpc-provider): convenience RPC endpoints per network
